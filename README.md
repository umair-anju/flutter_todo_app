# 📝 ToDo App – Flutter

A simple and user-friendly **ToDo application built with Flutter and Dart**.
The app allows users to create, manage, update, and delete their daily tasks.

## 🚀 Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📋 View pending and completed tasks
* 💾 Store tasks locally
* 📱 Responsive Flutter UI
* 🎨 Simple and clean design

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material UI**
* **Local Storage** *(if implemented in the project)*



## 📱 Supported Platforms

This Flutter application can be configured to run on:

* Android
* iOS
* Web
* Windows
* macOS
* Linux
